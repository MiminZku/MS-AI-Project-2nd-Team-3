# 마감 규칙 (AI 세션 요약)

> 이 파일은 Claude Code / Codex 등 AI 에이전트가 읽는 지시문입니다.

사용자가 "마감", "마감해줘", "wrap up" 등으로 세션 마감을 요청하면 다음을 순서대로 수행한다:

1. **이번 세션의 논의를 요약한다.** 5줄 이내. 포함할 것:
   - 내린 결정 또는 기운 방향 (예: "청킹은 문단 단위로 가기로 함")
   - 진행한 작업 (코드 유무 무관 — 조사/설계/비교도 포함)
   - 미해결 질문이나 내일 이어서 할 것
   - 잡담, 시행착오 과정, 코드 전문은 포함하지 않는다.
2. **파일로 저장한다.** 경로: `docs/ai-log/<github아이디>-<YYYY-MM-DD>.md`
   - github아이디는 `git config user.name` 또는 사용자에게 확인.
   - 같은 날 파일이 이미 있으면 덮어쓰지 말고 `---` 구분선 후 아래에 추가한다.
3. **커밋하고 푸시한다.**
   - 푸시 전에 반드시 `git pull --rebase` 를 실행한다.
   - 충돌이 나면 (특히 decisions.md): 양쪽 항목을 모두 살리는 방향으로 해결하고 진행한다. 결정 로그는 추가 전용 파일이므로 두 항목을 다 남기면 된다.
   - 커밋 메시지: `log: <이름> <날짜> 세션 요약`
4. 완료 후 사용자에게 저장된 요약을 한 번 보여준다.

## 요약 파일 형식

```markdown
## 2026-07-14 · <이름>

- 결정/방향: ...
- 작업: ...
- 미해결: ...
```
