## 작성 지침 (봇에게 주는 규칙)

- 1인칭("~했다", "~를 진행했다")으로, 본인이 쓴 것처럼 자연스럽게
- 커밋 diff와 AI 세션 요약(ai-log)에 있는 사실만 사용 — 없는 내용을 지어내지 않는다
- 각 항목 2~4줄, 전체 15줄 이내
- 과장 금지, 담백하게
