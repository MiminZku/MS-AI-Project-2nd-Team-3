# 데일리 리포트 — 2026-07-21 (최진웅)

## 오늘 한 일
- 이의신청 모달 UI를 새로 구현했다. 로그인 화면에 이의신청 버튼을 추가하고, 아이디·사유 입력 폼과 제출 로직을 `auth.js`에 작성했다.
- 이의신청 API 연동을 완료했다. 제출 엔드포인트(`/api/client/appeals`)를 수정하고, 모달 오픈 시 최근 이의신청 상태를 조회해 표시하는 `loadLatestAppeal` 함수를 추가했다.
- 게임 종료 후 재시작 선택 팝업(`showRestartChoice`)을 구현하고, 게임 종료 시 마이크 스트림 즉시 해제(`stopMicCapture`) 및 WebRTC 초기화(`closeWebRTC`) 처리를 추가했다.
- 음성 녹음 파일 포맷을 webm에서 wav로 변경하고, WebRTC 연결 시점을 채팅방 입장이 아닌 실제 게임 시작 시점으로 조정했다.
- 헤더에서 AI 모드 토글 버튼을 제거하고, 마이크 버튼 아이콘을 span으로 분리하는 등 전반적인 UI 정리를 진행했다. 분리돼 있던 `admin.html` 및 `admin_dashboard` 관련 파일도 제거했다.

## 배운 점 / 특이사항
- `toggleAI` 호출 시 버튼 요소가 없는 경우 null 참조 오류가 발생할 수 있어, 방어적 null 체크를 추가했다.
- 채팅 메시지의 `user` 필드를 클라이언트 전달값이 아닌 서버 측 식별값으로 교체해 위조 가능성을 차단했다(백엔드 수정).
