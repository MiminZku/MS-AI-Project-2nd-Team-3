## 배운 점 / 특이사항
- Teams Adaptive Card는 리터럴 `\n` 문자열을 줄바꿈으로 렌더하지 않으며, 실제 개행 문자만 인식한다는 점을 확인했다.
- GitHub Actions cron은 UTC 기준이고 예약 지연이 발생할 수 있어, 목표 시각보다 여유 있게 앞당겨 설정하는 것이 안전하다.
