## 🔴 2. 1순위 — 고인 모독 (가장 심각)

### 증상
4단계여야 할 문장을 **1단계**로 판정. **3단계 차이**의 최대 오차이며, 서로 다른 두 문장에서 동일하게 재현됨.

| 테스트 문장 | 모델 판정 | 정답 |
|---|---|---|
| 느그 **죽은** 할매도 이거보다는 잘하겠다 | 패드립 1 | **4** |
| **돌아가신** 아버지가 보면 뭐라 하시겠냐 | 패드립 1 | **4** |

### 원인
문서에 `4단계 · 최상급: 고인 모독이 결합되거나...` 규칙은 **있으나 예시가 없습니다.** 모델이 "죽은/돌아가신"을 고인으로 연결하지 못하고, 단순 가족 간접 암시(1단계)로 처리했습니다.

### 추가할 문구 — 「8. 패드립」 섹션 아래

```
[패드립 보정 — 고인 언급 판정]
· '죽은', '돌아가신', '고인', '하늘에 계신' 등 사망한 가족을 지칭하는 표현이
  비하·조롱과 결합되면, 표현이 완곡하더라도 패드립 4단계로 판정합니다.
· 고인 언급은 간접 암시(1단계)로 낮춰 볼 수 없습니다.

  예) 느그 죽은 할매도 이거보다는 잘하겠다   → 패드립 4
      돌아가신 아버지가 보면 뭐라 하시겠냐    → 패드립 4
      하늘에 계신 어머니가 우시겠다           → 패드립 4
```

**근거 강도: 강함** — 골드 데이터에 `느그 죽은 할매도 이거보다는 잘하겠다|1|패드립|4`로 이미 라벨링돼 있음

## 🔴 3. 2순위 — 관용 비속어 vs 차별적 비하

### 증상
2단계여야 할 문장을 **3단계**로 과대 판정 (2건).

| 테스트 문장 | 모델 판정 | 정답 | 모델이 밝힌 근거 |
|---|---|---|---|
| 병신같은 정글 뭐하냐 갱도 안 오고 | 욕설 3 | **2** | "장애인 비하 표현 '병신' 사용" |
| 강민기 손가락 하나 없냐? 왤케 못함? | 욕설 3 | **2** | "신체적 결함 조롱 = 차별적 비하" |

### 원인
3단계 정의에 `차별적 비하`가 있는데, **관용 비속어와의 경계 기준이 없습니다.** 모델이 "병신"의 어원(장애)을 근거로 차별적 비하 = 3단계로 판단했습니다.

문서 자체의 예시(`찐따같이 왜 그러냐 → 욕설 1`)와 골드 데이터(`병신 → 2`)를 보면 **팀 의도는 "관용 비속어는 차별적 비하로 보지 않는다"가 명확**하나, 그게 문서에 문장으로 적혀 있지 않습니다.

### 추가할 문구 — 「6. 욕설 강도」 섹션 아래

```
[욕설 강도 보정 — 관용적 비속어와 차별적 비하의 구분]
· 병신, 등신, 찐따, 새끼, 개시키 등 게임 채팅에서 관용적으로 쓰이는 비속어는
  어원이 특정 집단과 관련되더라도, 상대의 실제 정체성을 겨냥하지 않았다면
  '차별적 비하'로 보지 않습니다. 대상 지목 여부로만 1~2단계를 판정합니다.
· '차별적 비하(3단계)'는 상대의 실제 인종·국적·성별·성적지향·장애·종교 등
  정체성 속성을 직접 지목해 공격한 경우에만 적용합니다.

  예) 라준호 이새끼 병신임         → 욕설 2 (관용 비속어 + 대상 지목)
      병신같은 정글 뭐하냐          → 욕설 2
      강민기 손가락 하나 없냐?      → 욕설 2 (실제 장애를 지목한 것이 아님)
      너 진짜 장애인이냐? 손이 없냐  → 욕설 3 (실제 장애를 직접 지목)
```

**근거 강도: 강함** — 골드 데이터에 `병신같은 정글...|1|욕설강도|2`, `이 팀 전체가 다 병신들이야|1|욕설강도|2`, `강민기 손가락 하나 없냐?...|1|욕설강도|2` 모두 2단계로 라벨링돼 있음

> 📌 이 항목은 개발팀장이 처음 문제 제기한 사안입니다 ("2단계여야 하는데 3단계로 나온다").
> 원인이 검색 실패가 아니라 **문서 기준의 모호성**임이 이번 진단으로 확인됐습니다.

## 🟠 4. 3순위 — 비꼼·반어 (미탐 위험)

### 증상
명백한 비꼼을 **0단계(정상)** 로 완전히 놓쳤습니다.

| 테스트 문장 | 모델 판정 | 정답 |
|---|---|---|
| 니 어머니가 참 고생 많으시겠다 | **정상 0** | 패드립 2 |

모델 근거: *"'니 어머니'라는 가족 언급이 있으나 패드립 정의에서 요구하는 욕설·비하·혐오의 요소가 포함되어 있지 않음"*

### 원인
문서에 `위장 항의`(항의 형식을 취한 재조롱) 기준은 있으나, **칭찬·동정 형식의 비꼼**을 다루는 기준이 없습니다. 모델이 "욕설 단어가 없으면 정상"으로 판단했습니다.

제재 시스템에서 **미탐(놓침)은 오탐보다 위험할 수 있어** 우선순위를 높게 잡았습니다.

### 추가할 문구 — 「1. 공통 판단 원칙」 또는 「3. 0단계 및 화자 구분 세부 기준」 아래

```
[공통 보정 — 비꼼·반어 표현 판정]
· 겉으로 칭찬·동정·걱정의 형식을 취했더라도, 문맥상 상대를 조롱하거나
  깎아내리는 의도가 명백하면 해당 카테고리 기준대로 판정합니다.
· 욕설·비속어가 포함되지 않았다는 이유만으로 0단계로 판정하지 않습니다.

  예) 니 어머니가 참 고생 많으시겠다      → 패드립 2 (부모 직접 지칭 + 비꼼)
      실력 참 대단하시네요 배우고 갑니다   → 욕설 2 (반어적 조롱)
      머리 좋으신 분이 왜 이러실까         → 욕설 1~2
```

**근거 강도: 보통** — 테스트 문장이 신규 작성분이라 정답이 팀 검수 전입니다. 다만 문서의 `2단계: 부모·가족 구성원을 직접 지칭한 비하·조롱` 정의에 부합합니다.

## 🟡 5. 4순위 — 음란성: 요구·유도 표현

### 증상
3단계여야 할 문장을 2단계로 (2건).

| 테스트 문장 | 모델 판정 | 정답 |
|---|---|---|
| 카메라 켜고 몸 좀 보여줘봐 | 음란성 2 | **3** |
| 씨발련 몸이나 팔러 다니지 왜 겜하냐 | 음란성 2 | **3** |

### 원인
3단계 정의가 `성행위·신체 노출의 직접 묘사`로 돼 있어, 노출을 **요구**하는 표현은 "묘사가 아니다"라고 판단했습니다.

### 추가할 문구 — 「7. 음란성 발언」 섹션 아래

```
[음란성 발언 보정 — 요구·유도 표현]
· 직접 묘사뿐 아니라 신체 노출·사진·영상통화를 '요구·유도'하는 표현도
  3단계로 판정합니다. (보조 태그 '성적 괴롭힘' 병기)

  예) 카메라 켜고 몸 좀 보여줘봐   → 음란성 3 + 보조태그: 성적 괴롭힘
      사진 한 장만 보내봐          → 음란성 3 + 보조태그: 성적 괴롭힘

· 성매매·성적 대상화를 암시해 상대를 모욕하는 표현도 3단계입니다.

  예) 씨발련 몸이나 팔러 다니지 왜 겜하냐 → 음란성 3
```

**근거 강도: 강함(2번째 예시) / 보통(1번째 예시)** — `씨발련 몸이나 팔러...|1|음란성발언|3`은 골드 데이터에 있음. "카메라 켜고..."는 신규 작성분

## 🟡 6. 5순위 — 폭력성: 신상 단서 범위 명확화

### 증상

| 테스트 문장 | 모델 판정 | 정답 |

```

  현실에서 특정 가능한 모든 장소가 포함됩니다.
· 해당 장소를 특정하고 만남·대기 의사를 밝히면 4단계로 판정합니다.

  예) 니 회사 앞에서 기다리고 있을 테니 나와라 → 폭력성 4
      학교 앞에서 보자 도망가지 마라           → 폭력성 4
```

**근거 강도: 보통** — 신규 작성 문장이라 팀 검수 필요

## 8. 함께 알아둘 주의사항

### 판정 결과에 변동성이 있습니다
gpt-5-mini는 추론 모델이라 `temperature` 조절이 불가능하고, **같은 문장도 실행마다 한 단계씩 달라질 수 있습니다.** 실제로 동일 진단을 두 번 돌렸을 때 1차 세트 단계 정확도가 7/12 → 6/12로 변했습니다.

→ 보강 효과를 측정할 땐 **한 번 돌린 숫자를 확정치로 보지 말고**, 여러 번 돌려 비교하거나 "±1 수준 변동 있음"을 함께 표기해야 합니다.

### 근거 강도 구분
- **1·2순위** 예시는 팀이 검수한 골드 데이터에 이미 라벨링돼 있어 근거가 확실합니다. 바로 반영 가능합니다.
- **3·4·5순위** 예시 중 일부는 진단용으로 새로 작성한 문장이라, **팀 검수 후 확정**해 주세요. 정답이 다르다고 판단되시면 알려주시면 진단 스크립트의 기대값을 수정하겠습니다.
