# 📊 로컬 PostgreSQL 연결 테스트 가이드

이 문서는 로컬 개발 환경에 구성된 PostgreSQL 데이터베이스와의 연결을 확인하고 테스트하는 방법을 안내합니다.

---

## 1. 사전 준비 (의존성 설치)

테스트 스크립트 실행을 위해 다음 Python 패키지를 설치해야 합니다.

```bash
pip install psycopg2-binary python-dotenv
```

---

## 2. 환경 변수 설정 (`.env`)

`_backend` 폴더 아래에 `.env` 파일을 만들고, 데이터베이스 연결 URL을 입력합니다. (※ `.env` 파일은 절대 Git에 커밋하지 마세요.)

* **설정 형식:**
  ```env
  DATABASE_URL=postgresql://<유저명>:<비밀번호>@<호스트IP>:<포트>/<DB이름>
  ```

---

## 3. 테스트 실행

환경 변수 설정이 완료되었다면 다음 명령어로 테스트 스크립트를 실행합니다.

```bash
python test_db.py
```

### 정상 실행 시 출력 예시

성공적으로 연결되면 DB 스키마에 따라 테이블 조회가 이루어집니다. 초기에는 데이터가 비어 있으므로 아래와 같이 조회되는 것이 정상입니다.

```text
🔄 DB 접속을 시도합니다... (Target: postgresql://postgres:******@172.16.30.143:5432/apple_game)

==========================================
📊 데이터베이스 테이블 조회 결과
==========================================

🔹 테이블: users
----------------------------------------
   (데이터가 존재하지 않습니다.)

🔹 테이블: admins
----------------------------------------
   (데이터가 존재하지 않습니다.)

...

==========================================
✅ 데이터베이스 연결 및 조회 테스트를 성공적으로 마쳤습니다!
==========================================
```

---

## ❓ 문제 해결 (Troubleshooting)

### 1. `psycopg2.OperationalError: connection to server at "172.16.30.143", port 5432 failed`
* **원인**: 방화벽 차단 또는 PostgreSQL 설정 미비
* **해결방법**: 
  1. DB 서버 PC의 Windows 방화벽 인바운드 규칙에 `5432` 포트가 열려 있는지 확인합니다.
  2. `postgresql.conf`에서 `listen_addresses = '*'` 설정과 `pg_hba.conf`에서 팀원 IP 허용 설정이 되어 있는지 확인 후 PostgreSQL 서비스를 재시작합니다.
