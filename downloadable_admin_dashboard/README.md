# Downloadable Admin Dashboard

이 폴더는 Netlify에 바로 배포할 수 있는 정적 관리자 대시보드 파일들입니다.

## 포함 파일
- admin_dashboard.html: 로그인 화면 + 신고/제재/이의 신청 대시보드
- index.html: 배포 진입 파일
- netlify.toml: Netlify 정적 사이트 설정

## 실행 방법
1. 이 폴더 전체를 ZIP으로 압축합니다.
2. Netlify에서 "Deploy manually" 또는 Git 저장소 연결로 업로드합니다.
3. Publish directory는 루트 폴더(이 폴더)로 설정하면 됩니다.
